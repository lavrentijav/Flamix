# Flamix Demo - Демонстрационная версия

Это демонстрационная версия Flamix - системы управления файрволом Windows.

## Возможности

- ✅ Управление правилами Windows Firewall через netsh
- ✅ Блокировка/разблокировка IP адресов
- ✅ Блокировка конкретных портов
- ✅ Чтение правил из системы
- ✅ Сохранение правил в базу данных
- ✅ Проверка доступности через ping и PowerShell Test-NetConnection

## Структура проекта

```
demo/
├── demo_gui.py          # GUI приложение
├── demo_cli.py          # CLI модуль для блокировки IP
├── demo_checker.py      # Модуль проверки доступности
├── rs.txt               # Пример вывода netsh с правилами
├── data/                # База данных правил
│   └── rules.db
└── README.md           # Этот файл
```

## Запуск

Используйте `run_as_admin.bat` из корневой директории проекта для запуска с правами администратора.

## Требования

- Windows 10/11
- Python 3.8+
- PySide6
- Права администратора

## Оригинальный Flamix

Полная версия Flamix находится в корневой директории проекта и включает:
- Плагинную архитектуру
- API для плагинов
