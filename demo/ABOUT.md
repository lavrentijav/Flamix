# О Flamix

Flamix - это современная система управления файрволом с плагинной архитектурой.

## Основные компоненты

### flamix/api/

* **core\_api.py** - Основной API для взаимодействия с ядром системы
* **plugin\_interface.py** - Интерфейс для разработки плагинов

### flamix/cli/

* **firewall\_cli.py** - CLI интерфейс для управления файрволом через netsh

### flamix/database/

* **rules\_db.py** - База данных SQLite для хранения правил, плагинов и логов

### flamix/gui/

* **main.py** - Главное окно приложения
* **rule\_form.py** - Форма для создания/редактирования правил
* **traffic\_widget.py** - Виджет мониторинга сетевого трафика

### flamix/plugins/

* **loader.py** - Загрузчик плагинов
* **manager.py** - Менеджер плагинов

### flamix/security/

* **permission\_manager.py** - Система управления разрешениями для плагинов

### flamix/services/

* **app.py** - Основной сервис приложения
* **traffic\_monitor.py** - Мониторинг сетевого трафика

## Плагины

### netsh/

Плагин для управления Windows Firewall через NetSh с поддержкой:

* Создания правил для входящего/исходящего трафика
* Управления портами и протоколами
* Работы с профилями Windows Firewall
